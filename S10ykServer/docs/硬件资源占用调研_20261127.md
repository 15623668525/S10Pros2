# 服务器版 vs 单机版 硬件资源占用调研

- **日期**：2026-11-27 09:30–09:32（现场实测）
- **方法**：`systemctl show <unit> -p MemoryCurrent,CPUUsageNSec` + `ps/top/free/df/du` 快照；204 侧组件为临时拉起测量约 90 秒后停回原状（现态已还原，未改动 enable 状态）
- **适用版本基线**：v3.5.12

| 项 | 云服务器 204（服务器版主体） | 业务板 103（单机版主体，两版共用） |
|---|---|---|
| 架构 | x86_64 | aarch64 |
| CPU | Intel Xeon Silver 4410Y，48 核（2.0–3.9GHz） | 8× Cortex-A55 |

| 应用磁盘 | `/opt/s10yk` = 2.1 GB（含 venv/模型/wheels） | `/opt/s10yk` = 388 MB + `/opt/robot` = 88 MB |

## 四、两版对比总表

| 维度 | 服务器版 | 单机版 |
|---|---|---|
| 云侧占用 | ≈140 MB 内存 / <1.5 核（48核/128GB 上可忽略） | 无 |
| 板侧占用 | ≈135 MB / <0.2 核 | **≈1.05 GB / ≈1.3–1.5 核** |
| 板内存增量 | — | +~0.9 GB（主要是 persond） |
| 板 CPU 增量 | — | +1.3 核持续（persond），8×A55 上 load 可见抬升 |
| 最大消耗组件 | — | person_detect.py（onnxruntime CPU 推理） |
| 板磁盘 | 2.1 GB 在云侧 | 388 MB |
| 运行约束 | 依赖公网/frp 链路 | 完全本机自持；16 GB 内存余量大，可长期运行 |

## 五、结论与调优建议

1. **两版都可行**：单机版增量约 1 GB 内存 + 1.3 核，在 15.7 GB / 8×A55 板上余量充足（avail 11 GB）；CPU 上 persond 是唯一持续大户。
2. **persond 降档选项**（如需减负，`s10yk-persond` 单元环境变量）：
   - 模型 1280 → 640（显存/内存约降一半，精度略降）
   - 线程 `PERSON_THREADS=4 → 2`
   - 帧率 `PERSON_FPS=2 → 1`
   - 三项全开预估可把 1.3 核降到 ≈0.3–0.5 核、内存降到 ≈300–400 MB
3. **zenoh 取舍**：单机版无需 zenoh-bridge-dds（rclpy/drdds 直连），P5 已停并释放 112 MB；若回滚服务器版需重新 `enable --now zenoh-bridge-dds`。
4. **204 侧注意**：204 为共享服务器（同机有仿真/NVR 等大负载），S10YK 组件占用占比极小，但 204 的 `s10yk-backend` 当前 unit 状态为 failed（P5 停用遗留）+ `load_preset_durations` 文件缺失告警，回滚前需核查。
