## 实施中的发现与处置

1. **onnxruntime 1.32.0 无 aarch64 wheel**（204 版本为 x86_64），改用 1.28.0——YOLOv8n 标准 opset 兼容，实测推理正常。
2. **205 的 s10yk-backend.service 原为 0 字节文件（等效 masked）**——首装写入被吞，删除重写后 verify OK。
3. **厂商音频资产（audio.yaml+wav 976KB）只在 106 上有**，205 无——已从 106 拷至 205 同路径 /opt/robot/share/robot_drivers/audio_node_assets/，backend `load_preset_durations` 恢复正常（9 条音效时长全加载）。
4. **204→205 scp 失效**（sftp 子系统问题），改用 cat 管道传输，md5 双向校验一致。
5. 205 上 4 个 .py 编译产物：`/opt/s10yk/backend` 内含 mic_front 相关引用路径 /home/user/mic_front.py（本机已存在）——零改动。
